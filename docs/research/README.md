# YATL Research

This directory contains research-only tracks that are intentionally isolated from
the frozen production/validation path.

Current tracks:
- `crisis-lab/` — Crisis & Regime Stress Lab.
- `historical-strategy-lab/` — historical walk-forward / challenger research.
- `model-lab/` — isolated external-model research critic.
- `research-intake/` — external source provenance and candidate registry.

Rules:
- research evidence never mutates an active forward-validation registration;
- research results may create future candidate/policy versions only;
- negative findings are retained;
- historical, synthetic, forward and Live evidence remain explicitly separated.
