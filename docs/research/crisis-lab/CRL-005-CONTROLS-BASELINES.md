# CRL-005 — Control windows and baselines

Every crisis result must be interpreted against:
- pre-event window;
- event window;
- aftermath/recovery window;
- calm control window(s);
- NO-TRADE / CASH baseline;
- BUY-AND-HOLD research baseline.

Control windows are registered before final evaluation. Crisis-only cherry-picking
is forbidden.

Research question:
Did YATL survive/preserve capital better because of its architecture, or would the
same behavior appear in ordinary windows?

Exit gate: canonical comparison schema and deterministic baseline calculations.
