# CRL-009 — YATL Survival Certificate specification

The Survival Certificate is an internal technical artifact, not marketing and not
a profitability guarantee.

Minimum fields:
- YATL/strategy/risk-policy versions;
- event-catalog and dataset identities;
- crisis/control/random window counts;
- synthetic scenario counts;
- severity coverage;
- worst drawdown/equity excursion;
- survival/ruin flag;
- peak exposure;
- Kill Switch trigger count and reaction latency;
- worst slippage stress survived;
- false re-entry/out-of-regime violations;
- recovery summary;
- baseline comparisons;
- untested regimes/limitations;
- canonical evidence index/digest.

Any PASS-like label must be preregistered before the final run.

Exit gate: immutable schema + reconstruction test + explicit limitations.
